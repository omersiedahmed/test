# لاڤندرز120

بطاقة مؤشر سوق مستقل أنشأتها أداة **لاڤندرز (Lavenders · LAVNDR120)**.

An independent market index card generated with Lavenders.

- Card: https://omersiedahmed.github.io/test/
- Backend template: [backend/Code.gs](backend/Code.gs) (Google Apps Script; the live copy and its sheet run in the owner's own Google account)
- Orders, business sheets and images are not stored here.

The index reflects real consumer orders. There is no buying, selling or trading of shares, and no promise of returns.
